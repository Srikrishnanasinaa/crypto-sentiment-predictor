# Make the repo shine (and pin it)

## 1. Repository settings (About box, top right of the repo page)
**Description:** `Real-time crypto price forecasting from news sentiment (VADER) + Binance data. Walk-forward validation, fee-aware backtest, live scoreboard, Streamlit dashboard.`
**Topics:** `machine-learning` `data-science` `nlp` `sentiment-analysis` `time-series` `cryptocurrency` `streamlit` `scikit-learn` `python` `backtesting` `real-time`

## 2. Pin it to your profile
1. Open github.com and go to your profile page.
2. Click **Customize your pins**.
3. Tick `crypto-sentiment-predictor` (max 6) and click **Save pins**.

## 3. Add visuals (big impact)
1. Run the dashboard and take screenshots of each tab (Win + Shift + S).
2. Save them in `docs/` as `dashboard.png`, `comparison.png`, `backtest.png`.
3. Add this to the README under the title: `![Dashboard](docs/dashboard.png)`.
4. Optional: record a 30-second GIF with ScreenToGif and add it the same way.

## 4. Social preview
Repo **Settings → General → Social preview → Upload** a 1280x640 image (a dashboard screenshot works).

## 5. Release
Repo page → **Releases → Create a new release** → tag `v1.0.0` → title "Real-time crypto sentiment predictor" → paste the contents of `CHANGELOG.md`.

## 6. Optional public demo link
share.streamlit.io → New app → your repo → main file `app/dashboard.py`. For the forecast tab to work there, train on real data locally and commit the files in `models/` (`model_*.pkl`, then push).
